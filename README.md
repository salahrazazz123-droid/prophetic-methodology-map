المزايا الرئيسية

- 100 بطاقة حديث جاهزة وموثقة المصدر، مصنفة على الأبعاد العشرة (ثابت / متغير / غاية / يفكر / يشعر / يتصرف)
- منظومة الحكمة: تتبُّع رضا الله — تعريف من أربع طبقات (الغاية ← الثوابت المطلقة ← الثوابت المقيّدة ← المتغيرات) وميزان الرضا بأربعة فحوص وآلية الإزاحة، مع شريط تتبُّع لرضا الله في كل بُعد
- بحث فوري محلي (RAG) بلا انتظار ولا حاجة لمفتاح API، مع توحيد أشكال الحروف العربية وترتيب النتائج بالمطابقة
- تحليل ذكي بالذكاء الاصطناعي (Google Gemini) مع برومبت محكَّم بضوابط سلامة
- شارات توثيق لكل بطاقة: ✅ موثق / ⏳ قيد المراجعة / 🤖 مولّد آليًا
- رحلة تعلم تفاعلية من 7 مراحل للزائر الجديد
- مقارنة منهجية بين بطاقتين ومفضلة وتنزيل البطاقات بصيغة Markdown
- واجهة عربية كاملة RTL متجاوبة مع الجوال

التقنيات

- Streamlit (واجهة تفاعلية بالشريط العلوي `st.navigation`)
- نماذج لغوية كبيرة (LLMs) عبر Google Gemini API للتحليل الذكي
- RAG على مصادر معتمدة (فهرس محلي موثق + قاعدة صحيح البخاري SQLite)
- Knowledge Graph للربط الشبكي بين الثوابت والمتغيرات
- واجهة تفاعلية للخريطة الإشعاعية للأبعاد العشرة
- مراجعة شرعية بشرية كشرط نهائي لأي مخرج

النطاق الأولي

كتاب الإيمان من صحيح البخاري — 30 إلى 50 حديثًا موسّعًا، مع فهرس يغطي 100 بطاقة موزعة على الأبعاد العشرة (10 بطاقات لكل بُعد).

الضوابط العلمية والموثوقية

- لا حكم على الحديث (لا تصحيح ولا تضعيف)
- إحالة إلزامية للمصدر لكل معلومة شرعية
- مقاومة الهلوسة: عند الشك يُقال صراحة «لم أتحقق من هذا الحديث»
- لا فتوى: هذه الأداة استكشاف علمي وبحثي، والإحالة للمختص الشرعي
- الشفافية: الإفصاح الواضح أن الأداة مدعومة بالذكاء الاصطناعي وأن نتائجها تحتاج مراجعة

التثبيت والتشغيل محليًا

المتطلبات

- Python 3.9 أو أحدث
- مفتاح Google Gemini API (اختياري — يعمل التطبيق بدونه بوضع التحليل الفوري المحلي)

الخطوات

```bash
# 1) استنساخ المستودع
git clone https://github.com/salahrazazz123-droid/prophetic-methodology-map.git
cd prophetic-methodology-map

# 2) تثبيت المكتبات
pip install -r requirements.txt

# 3) (اختياري) إضافة مفتاح Gemini
mkdir -p .streamlit
echo 'GEMINI_API_KEY = "ضع-مفتاحك-هنا"' > .streamlit/secrets.toml

# 4) التشغيل
streamlit run app.py
```

يفتح التطبيق تلقائيًا على `http://localhost:8501`

ملاحظات التشغيل

- بدون مفتاح API: تعمل كل الصفحات والفهرس والبحث والمقارنة ورحلة التعلم، ويقتصر التعطيل على «التحليل الذكي» فقط
- قاعدة البخاري: ضع ملف `bukhari.json` بجانب `app.py` لتفعيل البحث في صحيح البخاري (ينشئ التطبيق قاعدة SQLite تلقائيًا)
- لا ترفع مفتاح API أو ملف `secrets.toml` إلى المستودع

داخل `app.py`:
- `DIMENSIONS` — الأبعاد العشرة بثوابتها ومتغيراتها
- `HADITH_CARDS` — 100 بطاقة حديث موثقة المصدر
- `TFS_DETAILS` — كيف كان يفكر ويشعر ويتصرف ﷺ في كل بُعد
- `SYSTEM_PROMPT` — برومبت التحليل المحكَّم بضوابط السلامة
- `VERIFICATION_OVERRIDES` — حالة توثيق كل مصدر
- دوال البحث المحلي (RAG مبسّط) والتحليل الفوري والذكي

أرشيف التطور (ميزات مؤجلة أو مرشّحة)

سُجّلت هنا أفكار راجعناها ولم تدخل النسخة الحالية، للرجوع إليها مستقبلًا:

- مراجعة نموذجين مزدوجة (Dual-Model Review): عرض نتيجتي نموذجين مختلفين جنبًا إلى جنب للمقارنة. القرار: مؤرشفة تلقائيًا — التعقيد لا يستحق الفائدة في النسخة الحالية.
- قاعدة hadith.db ببحث FTS5: بحث نصي كامل أسرع وأوسع في المصادر. الحالة: مرشحة — تتطلب رفع ملف قاعدة أكبر للمستودع.
- زر «أبلغ عن خطأ» داخل التطبيق: رابط مباشر إلى صفحة Issues في المستودع. الحالة: ✅ نُفّذ في التذييل (الإصدار 2.1.0).
- ميزان تفاعلي (حاسبة موازنة): إدخال موقفين وموازنتهما آليًا. القرار: مؤرشف — المنظومة تُعرض ولا تُقحم؛ لا حاسبات قسرية.
- ربط العوامل المزيِّنة بالأبعاد: خريطة «عدو لكل بُعد» ضمن آلية الإزاحة. الحالة: مرشحة للدراسة.
- قاعدة أوسع: إضافة الترمذي وأبي داود وابن ماجه إلى قاعدة البحث المحلية. الحالة: مرشحة.
