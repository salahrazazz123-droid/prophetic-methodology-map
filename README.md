# نظام استكشاف منهج النبي ﷺ

**خريطة إشعاعية للثوابت والمتغيرات في الأحاديث النبوية**

🔗 **الرابط المباشر (تجربة فورية):** https://prophetic-methodology-map.streamlit.app

---

## المسار

المسار الرابع: **أدوات المعرفة والتحقق لتمكين المعرفين بالإسلام**
تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026

المشارك: **صلاح رزاز كامل أحمد** (مشاركة فردية)

---

## المشكلة

تُقرأ الأحاديث النبوية عادةً في أبوابها الفقهية المتفرقة، لا في مركز منهج النبي ﷺ نفسه. والنتيجة: **تقديس المتغير** (الوسيلة والشكل) و**تحريف الثابت** (المبدأ والقيمة)، ويصبح المنهج أداة جدل بدل أن يكون هداية.

## الحل

أداة ذكية تصنّف الأحاديث على **عشرة أبعاد تغطي حياة الإنسان**، وتستخرج الثوابت والمتغيرات، وتربطها شبكيًا في خريطة إشعاعية تُظهر المنهج من مركزه: **رضا الله**.

المبدأ الأساسي: النبي ﷺ شخصية واحدة عاشت في زمن واحد ومكان واحد؛ فإذا ذُكر متغيرٌ فغالبًا يخدم ثابتًا، وإذا ذُكر ثابتٌ فغالبًا لتحقيق غاية.

### الأبعاد العشرة

المعرفة · القول · الفعل · الذات · الآخر · الزمن · المال · المقدس · السلطة · الجسد

## المزايا الرئيسية

- **100 مادة نصية (أحاديث ونصوص) منسوبة المصدر مع فحص أولي**، مصنفة على الأبعاد العشرة (ثابت / متغير / غاية / يفكر / يشعر / يتصرف) — مع شارات توثيق صادقة: ✅ موثق مقابل نص الكتاب / ⏳ قيد المراجعة / ⚠️ ضعيف عند كثير من المحدثين
- **منظومة الحكمة: تتبُّع رضا الله** — تعريف من أربع طبقات (الغاية ← الثوابت المطلقة ← الثوابت المقيّدة ← المتغيرات) وميزان الرضا بأربعة فحوص وآلية الإزاحة، مع شريط تتبُّع لرضا الله في كل بُعد
- **بحث فوري محلي (RAG)** بلا انتظار ولا حاجة لمفتاح API، مع توحيد أشكال الحروف العربية وترتيب النتائج بالمطابقة
- **تحليل ذكي بالذكاء الاصطناعي** (Google Gemini) مع برومبت محكَّم بضوابط سلامة
- **شارات توثيق تشرح نفسها** لكل بطاقة (اضغطها لتعرف معناها): ✅ موثق / ⏳ قيد المراجعة / ⚠️ ضعيف / 🤖 مولّد آليًا
- **رحلة تعلم تفاعلية** من 7 مراحل للزائر الجديد
- **مقارنة منهجية بين بطاقتين** ومفضلة وتنزيل البطاقات بصيغة Markdown
- **واجهة عربية كاملة RTL** متجاوبة مع الجوال

## التقنيات

- **Streamlit** (واجهة تفاعلية بالشريط العلوي `st.navigation`)
- **نماذج لغوية كبيرة (LLMs)** عبر Google Gemini API للتحليل الذكي
- **RAG على مصادر معتمدة** (فهرس محلي موثق + قاعدتي صحيح البخاري وصحيح مسلم SQLite)
- **خريطة مفاهيمية (Conceptual Map)** تربط الثوابت والمتغيرات بالأبعاد العشرة
- **واجهة تفاعلية للخريطة الإشعاعية** للأبعاد العشرة
- **مراجعة شرعية بشرية** كشرط نهائي لأي مخرج

## النطاق الأولي

كتاب الإيمان من صحيح البخاري — 30 إلى 50 حديثًا موسّعًا، مع فهرس يغطي 100 مادة نصية موزعة على الأبعاد العشرة (10 مواد لكل بُعد).

## الضوابط العلمية والموثوقية

- **لا حكم على الحديث** (لا تصحيح ولا تضعيف)
- **إحالة إلزامية للمصدر** لكل معلومة شرعية
- **مقاومة الهلوسة**: عند الشك يُقال صراحة «لم أتحقق من هذا الحديث»
- **لا فتوى**: هذه الأداة استكشاف علمي وبحثي، والإحالة للمختص الشرعي
- **الشفافية**: الإفصاح الواضح أن الأداة مدعومة بالذكاء الاصطناعي وأن نتائجها تحتاج مراجعة

## التثبيت والتشغيل محليًا

### المتطلبات

- Python 3.9 أو أحدث
- مفتاح Google Gemini API (اختياري — يعمل التطبيق بدونه بوضع التحليل الفوري المحلي)

### الخطوات

```bash
# 1) استنساخ المستودع
git clone https://github.com/salahrazazz123-droid/prophetic-methodology-map.git
cd prophetic-methodology-map

# 2) تثبيت المكتبات
pip install -r requirements.txt

# 3) (اختياري) إضافة مفتاح Gemini
mkdir -p .streamlit
echo 'GEMINI_API_KEY = "ضع-مفتاحك-هنا"' > .streamlit/secrets.toml

# 4) التشغيل
streamlit run app.py
